## ✨ Overview

This is my personal portfolio website, built with **React** to showcase who I am, the projects I've worked on, the skills I bring, and the easiest way to get in touch. It's a single-page app organized into four core sections — **About**, **Projects**, **Skills**, and **Contact** — designed to give visitors (recruiters, collaborators, fellow developers) a quick, clear picture of my work.

> 💭 *A portfolio isn't just a list of projects — it's the first impression before the conversation even starts.*

## 🚀 Features

| Section | Description |
|---|---|
| 👋 **About** | A short introduction — who I am, my background, and what I'm currently focused on |
| 💻 **Projects** | A showcase of selected projects with descriptions and links to live demos / repos |
| 🧠 **Skills** | An overview of the languages, frameworks, and tools I work with |
| 📬 **Contact** | A simple way for visitors to reach out or find my social/professional links |

## 🛠️ Tech Stack

- **React** — Component-based architecture powering the entire UI
- **JavaScript (ES6+)** — Application logic and interactivity
- **HTML5** — Semantic page structure
- **CSS3 / Sass** — Styling and responsive layout, with Sass for nested rules, variables, and mixins
- **GSAP** — Scroll-based and interactive animations across sections

## ⚙️ Getting Started

### Prerequisites

- Node.js (v16 or higher recommended)
- npm

### Installation

```bash
# 1. Clone the repository
git clone https://github.com/udaykx/Portfolio.git

# 2. Move into the project directory
cd Portfolio

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```

The site will be available at the local URL shown in your terminal (typically `http://localhost:5173` for Vite or `http://localhost:3000` for Create React App).

### Build for production

```bash
npm run build
```

<br/>

## 🎮 Usage

1. Open the site in your browser.
2. Scroll or navigate through **About**, **Projects**, **Skills**, and **Contact**.
3. Click into any project card to view more details or visit its live demo/repo.
4. Use the **Contact** section to reach out directly.
